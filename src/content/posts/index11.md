# 云析 YunX：一个初中生开源的网盘解析下载工具

## 一、项目简介

云析（YunX）是一个开源的网盘分享链接解析与下载工具，目标是解决一个很具体的痛点：**分享链接散落在多个网盘平台，每个平台都要单独装客户端，下载还要手动输入提取码。**

它的做法很简单：把分享链接整段粘贴进去，自动识别网盘平台、自动匹配提取码，解析出直链后直接下载。项目基于 **AGPL-3.0 协议**开源，安卓端由作者 CYQawa 开发，Windows 桌面端由社区开发者 tidain 移植。

值得一提的是开发背景。据项目说明，安卓版作者是一名初中生，因为个人没有电脑，所以只做了安卓端；Windows 桌面版是社区接力补上的。

## 三、核心功能

### 3.1 分享链接解析

识别主流网盘的分享链接，自动匹配提取码，无需手动拆分链接和提取码。复制分享链接后回到应用，还会自动提示一键粘贴解析。

### 3.2 高速下载

采用 **Range 分片并发 + 断点续传**。任务会保存请求头与固定的分片规划，下载中断后可以从断点继续，不需要从头再来。安卓版并发上限为 32，可以在设置中根据网络情况调整线程数。

### 3.3 临时转存清理

百度、迅雷、光鸭在取链后会清理临时转存；夸克则保留到下载完成或删除任务后再清理。

### 3.4 认证备份

使用用户口令派生密钥，以 **AES-GCM** 加密 Cookie / JWT 备份文件，登录凭证仅保存在本地。

### 3.5 多平台登录

不同网盘的登录方式不同，云析针对每个平台做了适配：

| 登录方式 | 适用平台 |
| :--- | :--- |
| WebView Cookie | 夸克、UC、百度、139、115 |
| 账号密码 / 短信验证码 | 迅雷、光鸭 |
| 账号密码换取 JWT | 123 云盘 |
| 账号密码 | 蓝奏云、蓝奏云优享版 |

## 四、使用流程

安卓端和 Windows 桌面端的操作流程基本一致：

1. **登录网盘**：在「网盘」页登录需要使用的网盘账号
2. **粘贴解析**：在「解析」页粘贴分享链接（可带提取码）
3. **浏览内容**：浏览分享内容，点击文件获取下载直链
4. **下载管理**：在「下载」页查看进度，支持暂停、继续、删除、打开

## 五、技术栈

| 分类 | 选型 |
| :--- | :--- |
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 持久化 | Room（KSP 注解处理）+ SharedPreferences |
| 网络 | OkHttp 4.12.0（请求 + 分片下载） |
| 构建 | Gradle + KSP |

环境要求：Android SDK minSdk 24，targetSdk 34。项目在 AndroidIDE 上开发调试，理论上兼容其他 Android 构建环境。

## 六、常见问题

<details>
<summary><b>百度网盘下载 / 转存不了？</b></summary>

你的账号被风控了。这是使用第三方解析工具访问百度网盘的已知风险，建议更换账号或避免使用百度网盘。

</details>

<details>
<summary><b>能否开发 PC 端？</b></summary>

安卓版作者个人没有电脑，故无法开发 PC 端。社区内已有人开发 PC 移植版：[YunX-Desktop](https://github.com/tidain/YunX-Desktop)。

</details>

<details>
<summary><b>下载速度慢怎么办？</b></summary>

可以在设置中调整下载线程数。网络条件好可以适当提高，遇到下载异常时优先检查网络或降低线程数。部分平台本身对非会员限速，工具无法绕过。

</details>

<details>
<summary><b>解析失败了怎么办？</b></summary>

平台接口可能随时调整，工具也可能随之失效。可以关注 GitHub 仓库的更新，或者到 QQ 群反馈。

</details>

## 七、注意事项

### 7.1 项目还比较新

云析迭代速度很快，但快速迭代也意味着它**还不是一个打磨多年的成熟产品**。遇到 Bug 或者平台接口变动导致解析失效，属于这类工具的日常。

### 7.2 合规使用

云析本身是开源工具，但第三方解析工具依赖各平台的非官方接口。建议**仅用于个人学习与技术交流**，不要用于商业用途。下载内容版权归原作者所有，请在下载后 24 小时内删除。

### 7.3 下载渠道

虽然工具本身免费，但网络上存在二次打包的收费版本甚至诈骗版本。**下载请认准 GitHub Releases**，不要从来路不明的网盘链接或第三方网站获取安装包。

> [!CAUTION] 反倒卖提醒
> 云析完全免费开源。如果下载到要钱的版本，说明被骗了，请立即退款。

## 八、总结

云析解决的问题很实际：**一个链接、一个工具、一次下载**，不用在多个网盘客户端之间来回切换。

它的开发背景也有点特别：一个初中生写出了安卓版，社区接力补上了 Windows 桌面版。代码开源、免费、无广告，覆盖了十个主流网盘和核心的下载需求。

但用之前需要清楚两点：**百度网盘有风控风险**，**项目还比较新，稳定性和长期可用性需要观察**。如果只是偶尔从几个网盘下载文件，不想为此安装一堆客户端，云析是一个值得尝试的选择。
